# あさのは保育園 ヘッダー＋ファーストビュー

架空の企業主導型保育園「あさのは保育園」のトップページです。現在のファーストビューは、正式なマーク単体画像をフレームとして使い、その中心で園写真が切り替わる「マーク写真装置」のビジュアルです。

## 制作方針

- 中心コンセプトは「はじめて預ける朝を、少し軽くする。」
- 背景色は朝の空気感が出る `#FDF6EE` を使用
- ファーストビューのコピー下に、園が何を支える場所かが初見で伝わる短い補助文を配置
- 制度説明よりも、入った瞬間の安心感と見学相談への導線を優先
- 企業枠・地域枠の入口は「我が家の利用枠を知りたい」という保護者目線の導線として残す
- 実写写真中心の落ち着いた保育園サイトとして設計
- ロゴは画像アセットとして使用
- ヘッダーは透過版の横組みロゴ画像を使用
- faviconとヒーローフレームは透過版の正式マーク単体画像を使用
- ファーストビュー右側は、正式マークの中心に写真が入って見える構造
- マーク写真装置と正式マーク枠はゆっくり呼吸する程度の控えめな動き
- 右側ビジュアル全体は `markFloat` でゆっくり呼吸し、周囲の丸と小さな葉が控えめに漂う
- PC表示では、左コピーを少し低め、右のマーク写真装置を少し上めに置いて余白を広く見せる
- 最終バランスとして、PC表示の右マーク写真装置を少し左へ寄せ、左コピーの圧を少し弱め、写真を少し明るく調整
- 1つの写真窓内で複数写真が数秒ごとにクロスフェード
- 写真は切り替わるたびに、ほんの少しだけゆっくりズーム
- 写真切り替え時に写真内部とマーク枠も少しだけ反応
- CTAボタンはホバー時に少しだけ近づく
- 左側コピーは `.text-run-in` を付けた各要素が、右側からさらにゆっくり入り、少しだけ行きすぎて静かに戻るように時間差で登場
- ファーストビュー直下に、対象・相談・見学の概要カードを配置
- `#slots` には、勤務先・未提携・地域枠・空き状況を家庭目線で確認できるセクションを配置
- スマホ表示の `#slots` は見出し・カード文字・余白を少し抑え、読みやすさを優先
- ファーストビュー下端に、次の情報へ続く気配として控えめなスクロールキューを配置
- ファーストビュー直下の概要カードセクションは縦余白を少し詰め、控えめな朝の道イラストを1点だけ配置
- 見学相談CTAは個人メールを開かず、ページ内の相談セクションへ移動
- `prefers-reduced-motion` に対応

## ロゴと写真について

ヘッダー用には、元の横組みロゴ画像から白背景だけを透過した `logo-horizontal-transparent.png` を使用しています。ヒーローの `.mark-frame` には、正式パスの `logo-mark.png` を使用しています。元の白背景つきマークは `logo-mark-white-bg-original.png` に退避し、`logo-mark.png` は白背景だけを透過したPNGとして扱っています。ロゴ形状は作り直していません。

現在のヒーロー写真は、手洗い・あそび・見学相談の素材を正式マークの中心窓内で切り替え、園の日常がのぞくように配置しています。写真窓はマーク内に収まりやすい縦横比に調整し、写真内部もごくゆっくり動かしています。本番運用時は、園の実写真に差し替えると信頼感がさらに高まります。

## 表示確認

- PC幅 1280px で、ヘッダーロゴ、コピー、正式マーク内の写真窓、CTAがファーストビュー内で自然に見えることを確認
- PC幅 1280px で、左右カラムの間隔が詰まりすぎず、右ビジュアルとCTAの圧が近すぎないことを確認
- PC幅 1280px で、右マーク写真装置・左コピー・写真明るさの最終バランスが崩れていないことを確認
- PC幅 1280px で、正式マーク画像と写真窓が重なり、CSS再現ロゴになっていないことを確認
- HTML上に `.hero-label`, `.hero-title`, `.hero-lead`, `.hero-note`, `.hero-actions`, `.text-run-in` が存在し、左コピーの登場アニメーションが適用されることを確認
- 補助文 `.hero-helper` が追加され、左コピーの情報量が重くなりすぎないことを確認
- サブCTA「我が家の利用枠を知りたい」から、家庭ごとの利用可能性を確認できる `#slots` セクションへ移動できることを確認
- スマホ幅で `#slots` の見出しが大きすぎず、カード内テキストと余白が圧迫感なく読めることを確認
- 写真窓1つに4枚の画像レイヤーがあり、JavaScriptで1枚ずつクロスフェードすることを確認
- 写真切り替え時に、マーク枠と写真窓が一体で控えめに反応することを確認
- 右側ビジュアルの呼吸、写真ズーム、丸と葉の漂い、CTAホバーが `prefers-reduced-motion` に配慮されていることを確認
- `mailto:` リンクが残っていないことを確認
- ファーストビュー下端にスクロールキューがあり、直下に概要カード3件が続くことを確認
- 概要カード前の余白が広すぎず、イラストが主役化していないことを確認
- スマホ幅 390px で、ロゴが潰れず、マーク内写真が分かるサイズで表示され、CTAが初期表示内に入ることを確認
- 確認用スクリーンショット: `preview-desktop-logo-world.png`, `preview-mobile-logo-world.png`
