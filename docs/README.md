# docs ディレクトリについて

このディレクトリは、GitHub Pagesで公開するためのWebサイト一式です。

## 公開対象

GitHub Pagesでは、以下の設定で公開する想定です。

```txt
Branch: main
Folder: /docs
```

実在の園ではなく、Webデザイン・情報設計・AI活用・保護者向け導線設計の学習制作物です。
