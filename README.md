# あさのは保育園 公式サイト

鹿児島市の企業主導型保育園「あさのは保育園」の静的Webサイトです。

## GitHub Pages 公開設定

このリポジトリは、`docs/` をGitHub Pages公開用ディレクトリとして使います。

GitHubへpush後、以下を設定してください。

1. GitHubリポジトリの `Settings` を開く
2. `Pages` を開く
3. `Build and deployment` を `Deploy from a branch` にする
4. Branchを `main`、Folderを `/docs` にする
5. `Save`

公開URLは通常、以下の形式になります。

```txt
https://<GitHubユーザー名>.github.io/<リポジトリ名>/
```

例:

```txt
https://uedatetsuhisa.github.io/asanoha-nursery-hp/
```

## スマホ確認

GitHub Pages公開後、上記URLをスマホのGoogle Chromeで開いて確認してください。

確認ポイント:

- ファーストビューで園名・写真・CTAが自然に見える
- `安全への取り組み` がスマホで読みやすい
- `Instagram` 導線が見つけやすい
- `見学・空き状況のご相談` フォームが表示される
- 横スクロールが出ない

## 編集元

制作元ファイルは `outputs/nursery-hp/` にあります。

GitHub Pages公開用には、同内容を `docs/` に配置しています。
