# あさのは保育園 Webサイト

0〜2歳児を対象とした、架空の企業主導型保育園「あさのは保育園」のWebサイトです。

保護者が初めて保育園に預ける不安を少し軽くできるように、  
見学相談、空き状況確認、利用枠の確認、園での毎日のイメージが伝わる構成を目指して制作しました。

## 公開URL

```txt
https://techuueda-bot.github.io/asanoha-nursery-hp/
```

## リポジトリ説明文

GitHubリポジトリの説明文には、以下を設定する想定です。

```txt
架空の企業主導型保育園「あさのは保育園」のWebサイト制作。保護者向け導線設計、情報設計、AI画像活用、レスポンシブUIの学習制作物です。
```

## 制作目的

このサイトは、実在する保育園の公式サイトではありません。  
Webデザイン、情報設計、マーケティング導線、AI活用の学習・制作物として作成した架空サイトです。

主な目的は、以下の検証です。

- 0〜2歳児を初めて預ける保護者に向けた安心感の設計
- 企業主導型保育園に対する不安をやわらげる情報設計
- 見学相談・空き状況確認へ自然につなげる導線設計
- スマホ閲覧を前提にした保護者向けUI
- 写真・ロゴ・余白・コピーを組み合わせたファーストビュー設計
- AI生成画像を仮素材として活用したWeb制作フロー

## 想定ペルソナ

- 20〜30代の共働き女性
- 育休復帰前後で保育園を探している
- 認可保育園・認定こども園を第一候補に考えている
- 企業主導型保育園に対して、安全面や保育の手厚さに不安がある
- スマホ検索とInstagramで園の雰囲気を確認する
- 鹿児島市内で車送迎や朝の負担も含めて比較検討する

## 注意事項

- このサイトは架空の保育園サイトです。
- 実在の園、所在地、職員、園児、サービス内容を示すものではありません。
- フォームはデモです。実際の送信は行われません。
